# Optic Terminal — keep this out of search results.
#
# The app has no sign-in by design, so anyone with the address can use it. On a
# random trycloudflare.com hostname that was obscurity by accident; on a real
# domain it stops being obscure, and an indexed page invites traffic this thing
# was never sized for — every visitor's ticker load hits a rate-limited free data
# feed shared by everyone else on the site.
#
# This is a request, not a control. Well-behaved crawlers honour it; anything
# that ignores robots.txt will crawl regardless, and the file itself is public,
# so it should never be used to hint at paths worth hiding. The only real access
# control would be authentication.
#
# The API is listed separately because a crawler walking /api/ticker/<symbol>
# would fan out into thousands of expensive requests.

User-agent: *
Disallow: /

# stating outright.
User-agent: GPTBot
Disallow: /

Disallow: /
