# Bug register

One row per defect. IDs are `BUG-nnn` in the order found and never reused. Priority follows directive 00
(P0 advice behaviour, broken core functions, incorrect financial data, security, critical failures; P1
simplicity, Milo reliability, Dossier usability, consistency, accessibility, first use; P2 polish).

Status words: OPEN, FIXED (implemented, not yet verified), VERIFIED (fix confirmed by the named test or
browser check), WONTFIX (with the reason), BLOCKED.
