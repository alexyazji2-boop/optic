# Feature registry

Filled in Phase 01 from the source and from the running app. Every route, tab and control has an ID that
later phases and the final audit refer to.

ID scheme: `F-<AREA>-<nn>`, for example `F-HOME-03`. Each entry records what it shows, its interactive
controls and their actions, its API dependencies, the preferences it reads or writes, whether it needs an
account, and its loading, error and empty states. "Source" means read from code; "Rendered" means seen in a
browser at a stated size.
